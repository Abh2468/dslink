DS touch injection test

This isolates one question: do synthetic mouse events reach the DS core at all? Everything else (phone, network, screen cropping) is removed. The emulator canvas is fully visible here — both DS screens, unhidden and unclipped.

Step 1. Load a DS ROM (and BIOS zip if your game needs one), then press Start.
Step 2 — control test. Once the game is running, click directly on the lower screen with your real mouse. If the game responds, real mouse input works.
If this does not work, the core isn't taking stylus input at all and no injection method will help.
Step 3 — injection test. Now inject a synthetic tap at the same spot without touching the mouse. Move your cursor away from the canvas first.
Real click works but injection doesn't → the core ignores untrusted events, and the two-device design needs a different approach. Both work → the bug is elsewhere in the main page (cropping or the network path), not the injection.
